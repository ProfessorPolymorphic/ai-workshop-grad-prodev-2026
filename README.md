# AI for Graduate Professional Development

Slides, prompts, and activities for a 2.5-hour workshop on AI in a graduate-level professional development course.

Barrie Robison, University of Idaho.

## The slides

Rendered deck: https://professorpolymorphic.github.io/ai-workshop-grad-prodev-2026/

Or open `index.html` in any modern browser. Arrow keys or the on-screen arrows move forward and back; some slides build one piece per press. Press `f` for full screen. Press `m` (or the &#9776; button) for a slide menu grouped by section; click any slide to jump to it. The slide number is kept in the URL (`#12`), so a reload keeps your place and you can link straight to a slide.

The deck is one self-contained HTML file plus the `img/` folder. No build step, no dependencies.

## Activities and examples

Hands-on materials live in `examples/`, one folder per activity, each with its own README.

## Note on illustrative content

The next-word sentence and its percentages, and the three "Inconsistent" runs, were written for these slides. They are illustrative, not measured. Running the prompt three times in Vandal Chat during the workshop gives real ones. The rainbow trout methods paragraph is invented for the input, process, output example.
